How scores are computed

  1. For each task, AgentLens merges five passing runs of that task into a reference PTA, the space of known-good solutions. Every run is scored against a reference that does not contain it.
  2. A model's runs are scored only against runs from other models. Including its own runs would raise its score by about three points per same-model donor, an advantage a new agent never gets.
  3. The five donors are drawn at random. Every run is scored under five fixed draws, and the table averages them, because a single draw can shift scores by a few points.
  4. The donor lists for every draw, task, and model are published, and scoring needs no LLM calls, so every number on this page can be reproduced exactly.

Submit your agent

Run the benchmark with your own model and harness, score the runs locally, and send us the results.

  1. Download the repository and install the scorer. It contains the 47 tasks (agentlens-bench/annotations/tasks.csv), the reference runs, and the scoring code. Scoring runs on CPU and needs no API keys. 
    git clone https://github.com/agentlens-framework/agentlens
cd agentlens && pip install ./sdk
  2. Run your agent on each of the 47 SWE-bench Verified tasks, five times per task, and check every patch with the official SWE-bench harness. Any harness works if it saves OpenHands or ATIF trajectories.
  3. List your runs in a CSV file, one row per run: the task, the path to its trajectory file, and whether the harness marked it resolved. 
    task_id,trajectory,resolved
django__django-11066,runs/django-11066/run1.json,true
  4. Score the runs. This uses the same five reference draws as every model on this page and prints your quality score, pass rate, and Lucky rate. 
    python leaderboard/score_submission.py runs.csv --format openhands \
  --name "My Agent" --model "my-model" --agent "MyHarness" \
  --trajectories-url https://example.org/my-trajectories \
  --out leaderboard/submissions/my-agent
  5. Open a pull request that adds your leaderboard/submissions/my-agent folder. We re-score your trajectories from the link you provide and add your agent to this page.
